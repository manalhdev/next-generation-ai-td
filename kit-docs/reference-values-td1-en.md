# TD 1: the twenty reference values

Published on 21 October 2026, during TD 1. These are the correct values of the twenty questions, computed on the shared database `boutique.sqlite` (seed 20260925) by an SQL query and checked by a separate Python computation on the CSV files. No value comes from a model.

## How to use them

1. Compute your own reference first: one SQL query per question, run on the database, checked a second way.
2. Then compare each of your values with this table.
3. If a value is different, find the cause in your query (period limits, age on the date, product list, cents), fix the query, and write the cause in your session report.
4. Your `reference-td1.csv` ends with these twenty values, each produced by your own query. A number copied without its query does not count.

Values are revenue excluding VAT, in euro cents, as the questions ask. The euro column only helps reading.
